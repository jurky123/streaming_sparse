# 首帧时间重定位下的 intersection 预算消融

基线使用未微调 intersection 的正式权重；首帧 24 个物理页固定精算，窗口滚动后从原始首帧 K 刷新时间 RoPE，重建首帧摘要及纠偏编码。每页 64 token，当前 chunk 有 72 页。初始两个 chunk、第 0 层和每个 clean 步都执行 Dense。这些位置的算法预算敏感性为零。真正有预算选择的是 chunk 2–40 的四个去噪步、层 1–29、12 个头，共 54,288 个位置/轨迹，索引从 0 开始。

## 预算

窗口 W，历史可选页 H=W−24−72。定义 N=floor(total×(W−24))；当前页数 A、历史页数 B=N−A；实际 p=A/72、q=B/H。自身页计入 A，首帧 24 页额外加入。扫描 total∈{5,8,10,12,15,20}%，将 N 的 0%、25%、50%、75%、100% 分给当前（四舍六入，遇精确半数到偶数），限于 [max(1,N−H),min(72,N)]，余数归历史。0% 分配仍保留 own。另设 p=100%、q≤5% / 10% 两档，B=floor(qH)。满窗口每 query 共 112 / 129 个精算页，分别占非锚点预算 88/408、105/408，明显高于 10%。每种窗口的实际整数页数见三个扫描 JSON 的 counts。

## Dense 教师与扫描

使用 B 的真实物理页、分组、首帧相位与 history 逐出机制，但每次注意力对窗口内全部 token 计算 Dense。forest_run/113 为探索，snow_ski/661、kitchen_cook/557 为留出，均运行完整 41 个 chunk。路由排序来自该 Dense 状态真实的部署 risk。每个位置固定一个可复现的 query 行，按层、头、步、chunk 轮转；排序使用所在 Q64 的路由。对每页求 exact logZ 和条件输出，对 4 个代表求近似 logZ（含 16 倍质量）及 rank8 条件输出，将每个预算的 exact/approx 页拼成稳定的 log-softmax。共享这些页统计后，一次 Dense rollout 即可评估 32 组配额。误差为 sum(||预测−Dense||²)/sum(||Dense||²)，保留每个位置的分子与分母。NPZ 索引为 [chunk, noisy step, layer−1, head, 预算]。前两个 chunk 是保留位；第 0 层和 clean 步不包含在稀疏曲线中。

该低成本扫描使用分区 risk 顺序，未逐预算重算 Full_Pset 交换；在纠偏开启的层/头/步上这是预筛近似。模块隔离测量在无纠偏的 layer 1、step 0 做全 72 个 Q64、全 12 头；使用真实融合 kernel 与同输入 BF16 Dense，另测两个分区的 top-k/拼接，5 组×6 次计时取中位数。闭环视频对入选候选运行完整 intersection，保留 7 层×3 头×step 0 的 swap；限定换出与换入同分区、禁止换出首帧与 own，审计所有四个窗口和纠偏开/关输出。训练、路由和视频指标应使用同一配额约定。

## 性能与验收

视频使用东京街景 long_0/701。warmup 7 个 chunk；wall 为 41 个 chunk 的独立热态墙钟；profile 单独跑 41 个 chunk。生成墙钟含首帧重定位和缓存更新，VAE 与落盘另行执行。渲染后评估首条稀疏接缝、首次滚窗处、尾部 RGB 和 CLIP，保存逐方案数值。该输入曾用于比较 B，不能充当盲测。精度/画面准入线需另定；在给定约束前保留速度、局部误差及视频指标，不按单一标量强行定默认预算。

模块理论主项按 FMA=2。全核 12 头、4608 查询、宽 128。Dense FLOP = 4×12×4608×64W×128；E 个精算页的 QK+双 BF16 AV = 6×12×4608×64E×128；补偿主项 = 2×12×4608×ceil16(W)×(4×128+2×128+2×3×16)，采用现有账本的 detail 填充口径。每形状独立测 Dense，模块参考时间=主项 FLOP/该形状 Dense 实测吞吐，gap=实测−参考。除非用阶段隔离实验测得，精算和补偿共享一个融合核的实际时长；拆分 FLOP 不用于冒充分段时间。排序、缓存、索引开销也不能用 Dense 张量吞吐精确折成时间。事件级设备计时存在异步重叠和记录开销，不与独立墙钟相加。

## 重训练

原 full_coverage 有训练 C（29×12 的 pool_k/pool_v/pool_feature 加共享训练 reader）、冻结 C 后训练部署 Full_Pset LocalReader 两段；旧代码的全局 10% mask、teacher/random 换页、数据根目录及协议哈希不能原样复用。锚点教师原始记录须包含重定位后的 Q/K/V、绝对 token IDs、offset、每页 FP64 logZ、N/Z、Dense 输出。train_pilot 使用 train split 的 forest_run/113，在首次稀疏、首次滚窗、中后段和末段（chunk 2/6/20/40）采集。用原 loader 验证 sum(N)/sum(Z) 回到 Dense；四条样本仅用于两阶段接线验证，不可导出作为部署模型。正式重训需单独的多个训练 prompt/seed、完整层头、独立 development、共同初始化/优化器/训练步数，以及训练前、后使用相同配额的验证。原东京街景和雪地猛犸不计入训练。原项目 C 阶段历史完成 66,816 次更新；新预算整轮时间必须按新数据实测，不沿用原吞吐作为实测结果。
