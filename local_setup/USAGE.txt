本机配置：/data/chenjiayu/zhikun/streaming_sparse

Python 3.10.19；PyTorch 2.6.0+cu124；torchvision 0.21.0+cu124。
依赖按 migration/requirements.lock.txt 安装；额外安装 ninja、lmdb、Flask、
Flask-SocketIO、OpenCV headless，补齐推理与演示辅助模块的依赖。
实际版本见 installed.freeze.txt。
Python 环境位于 streaming_sparse/.venv，不修改已有 conda 环境。

运行方式（先进入仓库根目录）：
  cd /data/chenjiayu/zhikun/streaming_sparse
  source streaming_sparse/.venv/bin/activate

推荐使用本机入口，自动切换工作目录、设置 CUDA 编译器并选择空闲显存最多的 GPU：
  bash local_setup/run.sh local_setup/check_environment.py
  bash local_setup/run.sh -m streaming_sparse.v08.audit --tiny-network
  bash local_setup/run.sh local_setup/check_cuda_backend.py

指定 GPU 时，在命令前设置 CUDA_VISIBLE_DEVICES，例如：
  CUDA_VISIBLE_DEVICES=4 bash local_setup/demo.sh

单 prompt 短视频推理（480x832，3 个 latent 帧，解码后 9 帧，16fps）：
  bash local_setup/demo.sh
  输出位于 local_setup/results/demo/。
  修改 local_setup/prompt.txt 即可使用自己的提示词。
  例如生成 12 个 latent 帧：bash local_setup/demo.sh --frames 12
  此演示采用原 Self-Forcing 模型和仓库提供的 SDPA fallback。

  Wan-AI/Wan2.1-T2V-1.3B@37ec512624d61f7aa208f7ea8140a131f93afc9a

  Wan 基础权重和 Self-Forcing checkpoint 存放在项目原生要求的路径。
  T5、VAE 和 tokenizer 通过符号链接复用 /data/chenjiayu/models/LiveAct/ 下
  SHA256 完全一致的文件；移动共享目录后需重新下载或恢复链接。
  验证记录见 local_setup/results/models.json。

本机网络下载入口：
  bash local_setup/run.sh local_setup/download_models.py
  此入口保留系统代理配置，以匿名方式下载公开模型，并检查原 revision/SHA256。
  原 migration/download_models.py 会清除代理，本机直连官方端点超时。
  本机已有 Hugging Face 令牌过期，公开资产使用 token=False 避免 401。
