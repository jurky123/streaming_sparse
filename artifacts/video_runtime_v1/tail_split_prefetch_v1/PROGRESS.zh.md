# 在最后一个精算页预取首个补偿块

固定 15% 总预算、首个 latent 帧全部精算。最后一个精算页固定读共享缓冲 1，同时用已空闲的缓冲 0 预取第一个有效补偿块。第 0 块的 16 页已全部进入精算，第 1 块先用缓冲 0，后续补偿块交替使用两个缓冲。正常路径复用已有的拷贝等待，回退路径在退出前等待这次拷贝完成。[候选构建](last_page.py)

## 模块验证

A100-SXM4-40GB 上使用四窗真实捕获，每个窗口在单卡上以 CUDA Graph 正反交替测量新旧核，每个窗口 20 对。另在同一张卡上逐窗口交替测原生 Dense、上一版和候选。下表的加速比取前一组配对中位数，吞吐对照取后一组同卡测量。

| 总页数 | 主核加速比 | 上一版 / Dense 吞吐 | 候选 / Dense 吞吐 |
|---|---:|---:|---:|
| 216 | 1.0156× | 89.25% | 90.56% |
| 288 | 1.0099× | 91.69% | 92.64% |
| 360 | 1.0094× | 93.06% | 93.84% |
| 432 | 1.0087× | 94.09% | 94.92% |

四窗正常输入、单 tile 回退、864 个 tile 全回退和单一主导键的输出均逐位一致。P216、P432 单 CTA racecheck 均为零 hazard。P432 的寄存器仍为 255 个，栈帧从 8 字节降为 0，动态 local load sectors 从 27,648 降为 0。barrier 等待从 7.83% 降至 6.38%，short scoreboard 从 9.73% 降至 8.11%，Tensor pipe 活跃率从 65.45% 增至 66.00%。[P432 同卡 Dense](dense_432.json) · [回退](last_page_guard_432.json) · [racecheck](last_race_432.txt) · [硬件计数](last_ncu.csv)

## 排除的实现

- 每个补偿块分别提交 K、V 并分两次等待，两张卡的 P432 配对加速比均约 0.9744×，输出逐位一致。增加的等待分散在两个块同步点，首组 QK HMMA 仍是 PC 热点。[PC 采样](split.json)
- 仅在精算归一化期间预取首个补偿块，四窗有 0.4%–0.5% 模块收益。单视频 5/8 更快，中位节省 3.39 ms；跨输入 6/10 更快，中位仅 1.05 ms。[单视频](cross_phase_video.json) · [跨输入](cross_phase_multi.json)
- 仅保留与最终方案相同的缓冲奇偶布局和循环入口、将首次搬运推迟至 guard 后，P432 相对上一版已达 1.0068×。将最后一页预取与这个对照直接交替测量，P432 额外快 1.0024×。本轮总收益包含代码生成和布局变化。[直接配对](late_vs_last_page_432.json)[后置搬运对照](../page_slope_v1/late_control_432.json)
