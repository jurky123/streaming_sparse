# 补偿代表缩放与掩码的合并

此前相邻权重两两配对的系数求和已做过视频对照。本轮保留原分母和四代表加减顺序，只对补偿 QK 的缩放进行试验。正式核在屏蔽位置直接选负无穷；候选给有效页零偏置，给屏蔽页负无穷偏置，同一次 FP32 FMA 完成乘尺度和加偏置。[源码变换](build.py) · [已有系数实验](../tail_butterfly_v1/PROGRESS.zh.md)

对四个真实窗口，各做 20 对 CUDA Graph 完整主核计时，单样本 8 次重放。P216/P288/P360/P432 的配对加速比分别为 1.00064×、1.00070×、1.00036×、0.99976×，所有捕获输出逐位相同。P432 动态指令从 207,794,592 降至 205,219,872，减少 1.24%，Tensor pipe 活跃率从 65.68% 到 65.75%。[P432 原始计时](maskbias_432.json) · [NCU](counters.csv)

另外对页掩码本身做了定向压力测试。只把头 0 的第 360 页代表 K 改为 NaN，再运行 P432。查询块 0 已经精算这一页，其补偿贡献应被屏蔽。正式实现在该头该查询块的 8192 个 BF16 元素全部与未注入时一致，候选却全部为 NaN，两者的精算 guard 标志均为零。候选无法保持正式核隔离屏蔽页的行为，且正常输入没有完整模块收益，故止于模块阶段。[压力测试与结果](masked_nonfinite.json) · [测试代码](masked_nonfinite.py)
