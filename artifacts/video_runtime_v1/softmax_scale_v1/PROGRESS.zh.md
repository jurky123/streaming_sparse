# 精算注意力的 softmax 缩放

部署时间线中融合核累计 852.9 ms，占 105 帧 base 时间约六分之一。432 页有 43 个精算页，原核每页在 64 个键上求最大值，更新运行中的行最大值，再计算概率并按新尺度合并 FP32 分子与分母。每次满窗口的精算 QK、双项 AV 合计约 116.87 GFLOPs。本轮保留这些矩阵乘，测试逐页归约和缩放造成的开销。[时间线](../repeated_context_v1/packed/device_timeline.json) · [计算量](../fused_exact_tail_v1/PROGRESS.zh.md)

432 页模块使用真实捕获的 Q/K/V、选页和摘要。其他窗口从同一输入截取并对页号取模。预热后交替测 16 对，每个计时含 8 次 CUDA Graph 回放。加速比为配对中位数，NMSE 为输出差的平方和除以原输出平方和。每个窗口包含 7,077,888 个 BF16 输出元素。

固定零偏移的模块加速约 5%，但 city_walk / 701 预热时执行失败。逐次检查输出，在第 27 次融合核调用（216 页）发现 558,456 个非有限值，同一输入的部署核输出全部有限。第二个核按查询块重算后该输入恢复有限，模块 NMSE 为 1.79e-9。[问题输入复核](nonfinite.json)

首页方案以第一个精算页的行最大值作为后续页的共同尺度。检查归一化分母，当块内任何一行超出 [1,1.21e24) 时用原始在线归约重算。测试构造首页 logits 为 0、第二页未缩放 QK 点积为 12,800 的输入。无重算的首页方案产生非有限值。将核内快慢函数使用相同 Triton 函数名时，压力测试亦失败；给候选函数独立命名后，核内重算与另起一个核重算均恢复为与部署核逐元素相同的输出。[压力测试](stress.json) · [测试入口](stress.py)

双页或四页合并可减少归约轮数，但 432 页双页共享内存从 80 KiB 增至 128 KiB。四页在双级流水下要求 224 KiB，超出设备上限；降为一级流水后模块明显回退。逐页自适应尺度的三个候选在双级流水下遇到 Triton 编译调度错误，一级流水实测均慢于基线。

## 单视频验收

city_walk / seed 701，105 帧，按 AB/BA 交替顺序在同卡同进程预热后测量。使用独立 Triton 名称的核内重算版本在 GPU7 的 5 对中全部更快，基线 / 候选耗时中位数 5.11174 / 5.07826 s，成对加速比中位数 1.00675×，节省中位数 34.29 ms（范围 20.66–37.09 ms）。另起一个核重算在 GPU6 的 5 对中也全部更快，节省中位数 30.75 ms。两种通过压力测试的版本在这条视频上的最终 NMSE 同为 0.25197，最大绝对差 4.96875，MAE 0.21772。前两段完全相同，第 3 段 NMSE 为 0.00387，最后一段为 0.70382。[核内重算](anchor_guard_named/single_video/base.json) · [另起一核](anchor_repair/single_video/base.json)

解码 105 帧后按项目既有的 RGB [21,101) 窗口比较。旧 / 新之间 LPIPS 0.22345、SSIM 0.68157、PSNR 17.06 dB。相对同 prompt、seed 的原生 Dense，LPIPS 从 0.37283 降至 0.36502，SSIM 从 0.45582 降至 0.42866，PSNR 从 14.705 增至 14.782 dB。该候选仅保留在实验目录，误差已提交用户判断。单视频五对计时收益同向，本轮只测试这一条视频。[逐帧指标](anchor_guard_named/quality.json) · [并排视频，左旧右新](anchor_guard_named/comparison.mp4)

## 正式部署

用户接受首页缩放候选。base 默认开启，intersection、step 沿用逐页归约；base 可用 `--no-anchor-scale` 切回。正式实现四种窗口逐元素等于已接受原型，压力测试触发回退后等于原始在线归约。city_walk / 701 的正式入口输出与已接受候选逐字节一致，关闭后与原 base 逐字节一致。同卡 GPU7 各自预热后 5 次中位数，base 5.07839 s、原生 Dense 6.47279 s，加速 1.27458×。按 1.40034× 验收线仍需缩短 0.45609 s。[正式入口](deployment.json) · [模块与回退](release_module.json)
