# P432 精算双项 AV 的短等待

对照为已部署的 page_prefetch。P432 主矩阵工作量 158.15 GFLOP，当前每次约 1.127 ms，约 140 TFLOP/s；按相应 Dense 有效吞吐折算约 0.760 ms。精算双项 AV 占 77.91 GFLOP。以下测试均在 A100 上使用完整融合核、同一份真实 P432 输入，与同卡同进程部署实现交替测量。每版预热 300 次，20 对，每次重放 8 遍。加速比取配对中位数。[计算口径](../compensation_scale_v1/attention_budget.json) · [模块程序](measure.py)

## 指令归因

Nsight Compute SourceCounters 单次满网格采样，31,658 个 short scoreboard 样本中，15,664 个（49.5%）映射到精算高低项 AV 的 dot 行，2,244 个映射到精算 QK。精算 AV 的这行对应 0 个 excessive shared wavefront；补偿的 BF16 高低项构造行则有 5,971,968 个。采样位置对应发生等待的指令，不能把样本比例当作可消除的时间比例。[按源码汇总](pc_samples.json) · [完整 NCU 报告](source_counters.ncu-rep)

## 满窗口候选

| 修改范围 | 配对加速 | 输出 |
|---|---:|---|
| 当前调度经 TTGIR 重编译 | 1.00006× | 逐位一致 |
| 高低项概率片段串行交接 | 0.8680× | 逐位一致 |
| 两个概率片段一起发起共享读取 | 0.99977× | 逐位一致 |
| 概率共享布局 perPhase=2 / 4 或转置 | 0.9653 / 0.8088 / 0.9406× | 逐位一致 |
| 概率共享布局 vec=4 | 0.9904× | NMSE 0.407，淘汰 |
| QK 维持 1×4，仅将 AV 改为 2×2 / 4×1 warp | 0.8837 / 0.6947× | 逐位一致 |
| 高低项分成独立的页内 FP32 累加链，再相加 | 0.9601–0.9609× | NMSE 7.22e-10，577 个 BF16 输出元素改变 |

分开 warp 分工的两个版本将页间 AV 分子一直留在新布局，只在精算循环出入口转换。2×2 的 spill 从 80 增到 86，4×1 增到 116。所有布局版本维持每线程 255 个寄存器和每 CTA 80 KiB 共享内存。[2×2](av_half_432.json) · [4×1](av_row_432.json)

另在 PTX 中重排 16 个独立输出片段的发射次序，各片段内部保留原来的 8 次 MMA 归约顺序。6 种重排的最终 cubin 的 kernel 机器码段与对照 SHA-256 完全相同。保留两条独立累加链后，机器码确实改变，spill 槽从 80 降到 76，但完整融合核慢约 4%。[PTX 实验程序](issue.py) · [机器码检查](row_4_binary.json) · [独立累加结果](parallel_4_432.json)

本轮停在 P432 模块验收。生产配置沿用已验收的错开 K/V 等待。上一轮整条视频融合核累计 797.19 ms，距 Dense 有效吞吐折算 528.33 ms 仍有 268.86 ms。后续可以单独定位补偿 64×16 系数从归约布局送入高低项 MMA 时的共享存储，先用完整融合核检查动态 bank conflict 和时间能否同时下降。
