# 在同一满窗口内分离精算页和补偿块的边际成本

固定 horse_field / 2027 的 P432 输入、每头摘要的实际跨度、K/V 布局和 864 个 CTA。用 CUDA 参数单独控制补偿循环截止位置，交叉测 32/48/64 个精算页与 6/16/26 个补偿块，共九点。缩短精算只取原路由前缀，缩短补偿只处理原块序列的前缀，二者均作性能诊断。九点输出有限且无回退。完整 64 页与 26 块时，输出与部署核逐位一致，诊断核分别比部署核多耗时 0.21%（CUDA event）和 0.13%（NCU base 时钟）。[实验入口](measure.py) · [原始 event](events.json) · [NCU](counters.csv)

| 同卡测法 | 每增加一个精算页，实测 / Dense 参照 µs | 每增加一个补偿块，实测 / Dense 参照 µs | 九点拟合最大残差 µs |
|---|---:|---:|---:|
| CUDA Graph 交替计时 | 12.233 / 13.253 | 9.216 / 7.040 | 0.775 |
| NCU base 时钟 | 15.334 / 16.407 | 11.506 / 8.716 | 1.396 |

每一整页和整块分别按 192 和 102 条 BF16 warp MMA 乘以 3456 个 warp 计，首个半宽补偿块的差额计入常数项。两套实测分别使用同卡原生 SDPA 的时间作为参照。固定时钟下，精算页的边际吞吐为 Dense 的 107.0%，补偿块为 75.8%。这些数是相对于额外工作量的斜率。线性模型常数项（event 57.02 µs、NCU 50.29 µs）包含没有单独测出的成本和外推，不能直接计作可节省时间。[拟合细节](fit.json)

## 把补偿分母的 warp 归约推迟到末尾

同一行的四个 lane 使用相同的在线 softmax 缩放。每个 lane 可在本地更新其分母份额，只在补偿结束时做 XOR 2、1 归约，替代每块的归约。保持代表 QK、双项 AV、分子缩放和精算 guard，浮点分母的求和顺序改变。四窗与正式核各交替测 20 对，P216/P288/P360/P432 的加速比为 0.9992×、0.9975×、0.9963×、0.9958×。四窗均无回退，模块 NMSE 为 1.86e−11 至 4.98e−11。该候选未通过模块速度验收，保留原有逐块分母归约。[源码变换](defer.py) · [P432 计时和误差](defer_432.json)
