# 精算和补偿之间的 Q 片段交接

当前 SM80 CUDA 两段均让每个 warp 负责 16 个查询行。两处 Q 加载的 lane、行、维坐标完全相同，正式 SASS 在进入补偿时又执行一组 32 条 LDG。候选直接将精算已经载入的 Q 操作数传给补偿 QK，保留选页、完整浮点累加顺序、分母和 guard。[源码变换](build.py)

四个真实窗口（horse_field / 2027）各做 20 对完整主核交替计时，每个样本重放 8 次。P216/P288/P360/P432 的加速比依次为 0.9873×、0.9854×、0.9831×、0.9814×。所有输出逐位一致，实测均无回退。[P216](qhandoff_216.json) · [P432](qhandoff_432.json)

P432 编译验证表明 Q 的第二组读取确已消失：静态 LDG 从 99 降至 67，两版均无 LDL/STL。NCU 中全局 load sectors 从 73,785,346 降至 72,900,864，local load sectors 均为零。Tensor pipe 活跃率从 65.77% 降至 64.57%，整个核动态指令增加 369,792 条。[硬件计数](counters.csv) · [静态指令](static.json)

逐 PC 汇总动态执行数，候选在精算和补偿热循环以外节省 103,680 条指令，其中 LDG 减少 110,592 条。精算热循环增加 214,272 条，其中 NOP 增加 221,184 条，等于每 warp 每个精算页多一条。补偿热循环增加 259,200 条，其中 LOP3 增加 172,800 条、SHF 增加 86,400 条，等于每 warp 每个常规补偿块多三条。这三段之和正好对应全核动态指令差。一次性去掉重复读取，改变了每页、每块的代码生成，未带来模块收益；当前使用原有 Q 重读路径。[分段指令差](instruction_delta.json) · [候选 SASS 采样](candidate.csv.gz) · [正式 SASS 采样](../page_arrival_v1/current.csv.gz)
