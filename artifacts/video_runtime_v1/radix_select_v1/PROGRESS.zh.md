# 稳定基数排序同时选页并标记复查行

满窗口每次路由对 12 × 72 行、每行 432 个分数选 43 页。旧路径先按分数排序以判断间隔，再按分数与页号排序生成 ID 和掩码。上一轮 105 帧时间线的 _rank 与 _select 合计 52.4 ms。新的 64 线程 CUDA 块用一次 CUB 稳定排序同时生成页序、掩码及需要复查的行。复查后仅重选这些行。分数转换为可排序的无符号整数，保留有符号零的原顺序，相同分数下较小页号优先。

7 个 216–432 页真实事件以 CUDA Graph 交错测量，64 线程组合模块加速 1.041–1.127×。Risk、ID、掩码逐项相同，重复值和正负零的构造用例也通过。该路径只在无 Full_Pset 纠正的匹配窗口启用，高精度复查及小窗口 tie_order 仍执行。[模块](module.json) · [设备时间线](device_timeline.json)
