# 路由图输入读写

在 BF16 投影 Risk 路径，路由阶段只读代表键、统计量、权重 theta 与实际启用的纠正编码。均值、detail 与 basis 留给后面的补偿 attention 直接读取。每次去掉的图输入拷贝为 12 × P × (128 + 24) 个 BF16 加上一份 basis。16 个 probe 按既有偏移，从 64 个 token 直接收集到 CUDA Graph 的输入缓冲，省去一份 3.54 MB 中间张量的写出及重读。

针对 P216/432 和基础/纠正分支，将省略的输入填 NaN，逐项核对选页 LUT、mask、Risk 和计数。四种组合完全相同；probe 与原 index_select 结果相同。包含 probe 收集和页面 staging 的模块加速 2.35–3.29×。[模块结果](module.json)
