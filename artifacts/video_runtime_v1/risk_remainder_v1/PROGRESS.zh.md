# Risk 分块核的尾块计算量

105 帧 base 时间线上，Risk 分块核累计 146.76 ms，288 页所在的第 3 段约 18.23 ms（段号从 0 起）。432 页有效 QK 计算量为 6.12 GFLOPs，八维方差投影约 0.38 GFLOPs。该窗口的 Nsight Compute 采样用时 271.14 µs，HBM 吞吐为峰值的 5.42%，L2 sector 命中率 95.86%，Tensor Core 活跃率为峰值的 11.29%，活跃 warp 为上限的 12.19%。[时间线](../repeated_context_v1/packed/device_timeline.json) · [硬件计数](roof.csv)

当前核按 128 页分块。288 页分成 128 + 128 + 32，将最后一块缩到 32，可省去该窗口 25% 的填充列。432 页分成 128 + 128 + 128 + 48，最后一块缩到 64，只能省去 12.5% 的填充列。比较两种实现，一种在同一 kernel 内按块号选择宽度，另一种将最后一块单独启动。两者均保留原始 128 页分组、输出地址及归一化边界。浮点归约树可随宽度改变。

七个真实输入共用当前部署的通道布局。计时包含统计转置、分块计算和最终归一化，在 CUDA Graph 中交替测 20 对，每次重放 16 遍。下表为成对加速比的中位数。

base 单视频 city_walk / 701 测 8 对，4 对更快，成对加速比中位数 0.99990×，候选耗时中位数多 0.51 ms（按成对差值）。因测速波动，另在同卡配对测试 5 个 prompt，各跑 seed 703 和 704，10 对中 6 对更快，成对加速比中位数 1.00022×，节省中位数 1.12 ms，范围为 −9.49 至 +11.08 ms。按执行顺序分组，基线先跑时节省中位数 −0.35 ms，候选先跑时 +1.95 ms。18 对最终 latent 均逐字节一致，路由计数相同。

288 页的模块从 0.24291 ms 降到 0.22573 ms，但该窗口只占视频的一段。以该段分块核的 18.23 ms 粗估，按 1.076× 折算，视频节省量级约为 1.3 ms。多视频的时间差跨零且单视频收益方向相反，候选保留为实验，现有部署继续使用原核。[单视频](single_video/base.json) · [5 × 2 验证](multi_video/base.json) · [模块入口](measure.py) · [视频入口](video.py)
