# 首页缩放精算的归一化分母

启用首页缩放的 base 在 105 帧轨迹中，融合注意力核 CUDA 时间累计 838.82 ms。满窗口每次处理 43 个精算页，每头每个查询块内有 64 行，每页有 64 个键。首页尺度固定时，各页概率共享同一个缩放因子，因此分母可以先按页内键位置跨页相加，最后一次性对 64 个键位置求和。每个查询行的 64 列归约由 43 次降到 1 次；43 页的 QK 和双项 AV 矩阵乘全部保留。数学上的分母相同，FP32 加法顺序改变。越界查询块继续调用原在线归约。[变更前时间线](device_timeline.json)

对比当前部署基线，满窗口的 PTX 静态 butterfly shuffle 计数从 116 减到 96，BF16 MMA 均为 684 条（含分支及回退路径）。CUDA Graph 预热后交替测 16 对，每次重放 8 遍。432 页用实际捕获输入；其余窗口基于同一输入缩短窗口并对选页编号取模。[原型模块](mass64.json) · [正式实现复核](release.json) · [溢出回退](stress.json)

| 页数 | 基线 / 上线实现 ms | 成对加速比 | 对基线 NMSE | 上线与接受原型逐位相等 |
|---:|---:|---:|---:|---|
| 432 | 1.18266 / 1.14451 | 1.03344× | 7.11e-10 | True |
| 360 | 1.02835 / 1.00045 | 1.02783× | 5.55e-10 | True |
| 288 | 0.79802 / 0.77498 | 1.02947× | 4.38e-10 | True |
| 216 | 0.64320 / 0.61683 | 1.04211× | 3.33e-10 | True |

另外对比了分开跨页累加 AV 高低项、将 AV 直接累入历史值、每两页合并行求和，以及只保留 2–32 个分母部分和。跨页分开累加 AV 高低项在 432 页为 0.951×；直接将高项累入历史值为 1.006×，但有 18,571 个 BF16 元素不同；选定的分母方案在同一输入只有 244 个元素不同。每两页一起归约在满窗口回退到约 0.55×。[AV 高低项](split.json) · [高项直接累加](chainhi.json) · [两页归约](twosum.json)
