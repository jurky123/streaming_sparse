# 固定窗口测量精算与补偿的边际耗时

正式基线为固定 15% 总预算、首个 latent 帧全部精算的 CUDA 版本，使用 lane 内四代表、复用均值质量和 128 位输出写回。三个模式的 105 帧生成中位数分别为 base 5.11830 s、intersection 5.17405 s、step 5.84579 s。[正式测量](../tail_maximum_v1/vector_release.json)

固定每个窗口的捕获输入，分别测试 32、40、48、56、64 个精算页。缩短列表保留前缀，扩展列表补入未选页，每次检查回退标志。每个窗口交替测量 Dense 与五种列表长度。两张 GPU 分别正序、倒序测四窗。[模块脚本](measure.py)

用每个组合的耗时中位数拟合常数项、精算页数、补偿块数（总页数向上除以 16 再减 1）。Dense 参照按同窗实测吞吐折算两类矩阵工作量。单位为微秒。

| 测序 | 每精算页实测 / 参照 | 每补偿块实测 / 参照 | 实测最大绝对拟合残差 |
|---|---:|---:|---:|
| 正序 | 12.10 / 13.09 | 9.56 / 6.96 | 3.23 |
| 倒序 | 12.16 / 13.17 | 9.22 / 6.63 | 0.71 |

两次测量中，每增加一个精算页都比折算参照省约 1 µs，每增加一个补偿块则多约 2.6 µs。补偿块数随窗口一起变化，其斜率包含其他随窗口增长的开销。常数项来自外推。下一轮值得优先拆测补偿循环。[拟合结果](fit.json)

另测 Q 操作数经每 warp 共享缓冲、用 ldmatrix 装入的路径。P432 只改精算、只改补偿和两处均改，相对正式核加速比分别为 0.9731×、0.9866×、0.9566×。三者输出逐位一致，模块均回退，结束这条路径，未进入视频验收。[精算](exact_query_432.json) · [补偿](tail_query_432.json) · [两处合用](both_query_432.json)
