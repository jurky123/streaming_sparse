# SM80 已接受的选页读取优化

每个 warp 协作预读选中页的 K/V 偏移，循环内通过 shuffle 广播。在精算循环中构造补偿掩码，复用已有同步点。base 沿用固定 15% 总预算、24 页首帧锚点和跨页双项 BF16 AV。

| 窗口页数 | 上版主核 ms | 正式主核 ms | 配对加速比 |
|---:|---:|---:|---:|
| 216 | 0.7841 | 0.7765 | 1.010× |
| 288 | 0.8285 | 0.8188 | 1.012× |
| 360 | 1.0058 | 0.9929 | 1.013× |
| 432 | 1.1759 | 1.1596 | 1.014× |

四窗正常、部分和全部回退用例均逐位一致。P432 的 long scoreboard 从 5.26% 降到 3.64%，Tensor pipe 活跃率从 59.12% 升到 59.89%。

三档正式入口在同一张 A100 上依次运行 city_walk / 701，512×768、105 帧，预热一次后取五次生成时间的中位数。

| 模式 | 生成时间 s | 对 Dense 的 latent NMSE |
|---|---:|---:|
| base | 5.22044 | 0.536715 |
| intersection | 5.17750 | 0.379339 |
| step | 5.87950 | 0.347492 |

各档输出与上一版对应 latent 逐位一致。独立的交替计时中，正式 base 比上一版 8/8 更快，中位节省 6.77 ms。原型在 5 prompt × 2 seed 上 8/10 更快，中位节省 9.00 ms，十组输出逐位一致。归因使用同轮配对差值。

105 帧设备累计主核 812.28 ms、准备 38.90 ms、回退检查 8.72 ms，合计 859.89 ms。上一版对应合计 870.65 ms。147.510 TFLOP 主项对应主核 181.60 TFLOP/s。按历史同窗 Dense 吞吐折算的固定参照 712.91 ms，主核差 99.36 ms，含准备和检查差 146.98 ms。本轮同卡重新交替测量各窗口 Dense 与主核，折算参照为 707.31 ms。

8 warp 双查询块共享首帧页与摘要的 CUDA 候选在 P432 逐位一致，速度为原版的 0.824×，Tensor 活跃率降至约 48.7%。将精算 Q 寄存器传到补偿的候选相对原版为 1.002×，低于已接受版本。重复同一页的诊断中，将每轮拷贝改为只拷一次，从 1.160 降至 1.039 ms；这项测试改变了输入页序列，仅用于定位搬运和同步的开销。
