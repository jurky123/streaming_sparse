# LayerNorm 帧调制与分组中心化融合

1536 维、4608 token 的块输入在同一核函数中完成 LayerNorm 和帧调制。Welford 的输入分配、warp 归约顺序、BF16 归一化输出和调制乘法的舍入点与当前 PyTorch CUDA 路径一致。每次调用省去写出及重读一个 14.16 MB 张量。三种输入幅度的完整模块 2.107–2.264×，输出字节全部相等。此项用于三档及原生 Dense。[模块结果](../layernorm_mod_v1/module.json)

32、64、128 token 的分组继续使用原有四轮幂迭代，在同一 CUDA 块完成按列中心化、方差、argmax 和后续迭代。浮点累加次序复现 PyTorch 的 strided mean，方差相同的维度按首个索引选取。四流完整分组由 1.311 降到 1.223 ms/层，三个尺寸的原始分数、分组索引和 K/V 均相同。[模块结果](../raw_group_direction_v1/module.json)
