# 分组特征计算与空间 softmax

105 帧 base 的 GPU 时间线中，分组 softmax 各次调用累计 89.3 ms。每层的 12 × 4608 × 32 个 FP32 分数占 7.08 MB，旧核扫描三次并写一次。新核一次读入共享内存，复用指数结果，按原 32 条累加链归约，一次写回。逻辑全局读写从 28.31 MB 降至 14.16 MB。独立 CUDA Graph 中位耗时 0.1384 → 0.0412 ms，3.36×。[GPU 时间线](../root_group_direction_v1/device_timeline.json) [softmax 模块](../group_staged_v1/module.json)

两处逐元素融合分别计算响应及其平方、归一化及加权相加。保留原 PyTorch 均值归约与 FP32 除法。真实输入、缩放输入与零输入的 32 维特征逐位一致。四流完整分组 1.0369 → 0.9403 ms/层，1.103×，四组输入的 K、V 和顺序一致。[特征对照](features.json) [分组对照](module.json)
