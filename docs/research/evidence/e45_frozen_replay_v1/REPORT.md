# E45：E43冻结补证与邻近状态留出

复用E43最终P/L，无训练、无新Query、无开发或Test评价。已见48事件/96状态；每事件预先固定一个新背景交换，共48个留出状态。留出只改变集合，不检验Query或轨迹泛化。

背景端点固定为原Medium之外第二个合法精算页与第二个合法近似页，保护own；未按真实收益挑选。协议在回放前落盘。

## P→L移植与身份

将最终P的FP32页面系数填入共享L表，后续保留相同BF16转换、φ和评分。两个种子各144状态的响应、β、全部512评分逐位一致；原E43最终P/L的96状态评分与E44补存矩阵也逐位一致。L能表达P在这批输入上的配置；原L较差只能说明有限优化未到达该配置，不能证明L表达空间更小。

E44物理哈希审计重新核验原token/K/V和摘要，未发现摘要等价而KV不同的身份碰撞。本轮再次核验并复用；两个tile/集合状态共享同一组系数。

## 对原评审的记录

保留E43的正面信号：小Reader可以在受限训练范围学到有用页面选择信息。Seed17原Set相对Independent优势基本未扩大，seed29最终Independent略高于Set，不能将恢复提高等同于组合交互能力提高。P局部未加权MSE上升不等于加权训练local loss上升；原E43没有分列三项曲线，该缺项不由后续实验追认补齐。

Teacher是真实M16/B16评分规则而非Q64完整Oracle；P可在训练状态上超过它，不代表预测比真值准确。巨大逐例相对退化须与绝对NMSE并列，原极小初始误差事件全部保留。

## 复现归档与限制

补齐E43导入闭包中的未归档代码，dependency_manifest.json逐文件记录SHA。已有工作区中部分依赖相对Git存在改动，本轮不覆盖生产文件；精确实际源码闭包另存source_snapshot.tar.gz。只克隆代码仍缺原始模型和规范数据：本轮不声称裸仓库可完整重训。

本轮冻结回放不能证明未见Query、未见轨迹或线上可靠性，也不启动新的训练。邻近集合的收益仅是一次锁定的局部外推检查，不能根据结果增选更多状态。

## 冻结补证的结论

- P→L移植逐位一致，明确排除“L不能表示P最终配置”的解释；仍不能从此识别原L的具体优化瓶颈。
- 已训练96状态上，当前状态重新评分比交叉沿用偏好的汇总恢复增益仅约0.09/0.82个百分点。seed29的Risk与BgSwap存在相反方向的大变化，合并后容易掩盖；不能称为两个状态上都可靠适应。
- 新背景留出状态Set恢复37.06%/72.09%，说明收益并非完全局限于原96个集合状态；但这是同Query、同候选池的邻近集合，不能称Query/轨迹泛化。相比沿用Risk偏好，仅增约0.52/0.32个百分点，H_loss反而略高。
- 因此保留“Reader具有有限决策可拟合性”的积极结论，同时仍缺强而稳定的集合条件增益证据。没有以本轮结果启动新训练、扩大模型或解封Test。
