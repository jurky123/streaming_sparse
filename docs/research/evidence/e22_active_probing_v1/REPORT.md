# E22：Active Residual Probing 第一阶段

结论：每子组2 token（每页8 token）出现同信息集合决策的正信号：两例均5/5种子正收益，平均优于独立残差排序；每子组1 token则集合方法平均退化。全页探测成本仍高，尚未证明质量匹配下可节省更多精算工作。因此信息门槛通过、成本门槛未通过；不扩大数据或实现kernel，第二阶段未运行。

## 固定范围与同信息对照

仅两份旧快照（city_walk/horse_field、s101/c5/l15/step0/head8/t61）。Q64/Page64、410页、41精确页、own保护、原Risk初选，全部页真实KV分层均匀无放回探测；每组b=1/2/4，种子17/29/43/71/101。每组使用固定随机排列前b个形成嵌套样本，计划在运行前保存。5次随机采样不是5个独立QKV样本。

主候选池Medium：Risk最低的16个可移出精确页、Risk最高的32个未选页；另列全部14760动作诊断。两方法共用同一批探测分子/分母及其估计Dense输出，均只允许一次交换和no-op。Probe-Independent分数为页面平均平方残差/估计Dense分母平方，选择s_add−s_remove最大正动作；不是重排41页。Probe-Set最小化估计Dense与当前混合输出的平方差，分母随集合变化。政策不读取真实Dense输出或真实残差；真值仅用于评价。

BF16 K/V每token512字节，读取按每head/tile独立扫描、不假设跨tile缓存复用；QK+AV为4×M×tokens×128 FLOPs。b2额外读取等于原41页精算KV读取的125%，QK/AV约31.25%。Medium仅交换范数下界另为1.812 GFLOPs/层，完整候选为52.235 GFLOPs/层，均不含完整I/B/分母、特征、exp、排序、访存和启动。

可直接读取原KV，不必重复缓存；若打包历史样本缓存以改善访问，会新增存储。当前72页样本每去噪调用更新。理论逻辑读取不等于实际HBM流量，小样本非连续访问还可能放大事务。最终41页不等于只计算41页：另有全页探测、路由评分；若先执行Risk再交换，还需新增精算与中间贡献复用，本轮没有先执行Risk两遍的设计。

固定预算下没有实测质量匹配的精算页减少或整体延迟收益，故成本门槛尚未通过；不能断言主动探测最终不经济，也不能据质量正信号直接进入kernel。候选页＋加权背景抽样、已选页反馈校准均标记未运行，保留下一步条件性研究。
