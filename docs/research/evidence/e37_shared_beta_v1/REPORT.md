# E37-A：Query共享β校准的离线能力诊断

冻结E29两个种子，每种子288个开发head–tile（两条轨迹各144例）。原R4、局部响应、Risk mask、Medium512、M16 probes、一次交换/no-op均保持不变。最终使用原真实Q64 NMSE收益；无训练、新QKV、原始KV读取或Test。

## 预登记与实现

选择摘要mass²作为唯一拟合权重，沿用既有质量诊断的尺度口径。对每个Query分别计算 b=Σm²(β真实−β预测)/Σm²；A2在原48候选页与背景页内分别计算。稳定计算采用组内softmax(2logmass)，不裁剪、不搜索偏移或权重、不以动作收益调参。四种方法全部使用相同预测局部响应；教师偏移使用当前Query真实β，不可在线获得。

五状态共同面板沿用E30。候选分组固定为原Medium的48页，跨状态不重新选池或重新分组；每次重新计算完整预测集合目标。教师拟合仅涉及原16个probes，不读取其余48 Query标签来拟合。独立评分和Set共享同一β与响应信息。

## 解释边界与成本

这是固定mass²回归下的解析教师诊断，不是这一类模型对真实动作收益的最优上界。失败只限制当前共享偏移方案，不能证明R4信息论不足或所有Query校准必然无效。共同β平移在全精确预测输出的页面softmax中会抵消，但混合输出同时含未修正摘要页，因此仍改变精确/近似相对质量，不能当作无作用的全局归一化。

当前阶段没有部署模块。若未来预测两个标量，逐Query–Page加法为16×410×864=5,667,840次/层，约0.00567 GFLOPs；无新增每页缓存或KV读取。聚合特征、校准器、额外扫描与融合成本尚未实现，不能将加法量当作总延迟。

来源为E30冻结全Query响应/β缓存与原面板，读取规范事件仅为Dense能量离线单位对齐和元数据；不加载raw KV文件、不重新执行Attention。正Dense归一化常数不进入模型，不影响排序或no-op。详见审计、源哈希与逐事件CSV。


## 主要判断

A2双偏移确有部分信息价值：两种子的实际Set恢复均提高，并且均超过同信息Independent；但只恢复E29→TrueBeta缺口的31.56%和11.09%，未达到50%。A1单偏移则连跨种子的收益改善都不稳定。停止当前共享校准，不训练B，不增加组数或改权重。

可靠性仍不足。A2退化数从95/91降至83/80，P10改善，但逐例平均仍为−3.31%/−3.56%。Seed29最差绝对NMSE增量和逐例平均比E29更差，因此不能只凭汇总正收益或较少错误次数判定成功。

回归和决策再次分离：双偏移解释的汇总mass²误差约99.68%/99.73%，事件/Query等权则为64.62%/62.92%。前者并不表示约99.7%的页面误差或组合信息都已恢复；层级和集中度如下，完整分组见quality_summary.csv、generalization.csv。

- seed17：layer29占原加权误差99.84%；最大单事件占7.82%，前五事件占34.41%。

- seed29：layer29占原加权误差99.86%；最大单事件占7.77%，前五事件占34.06%。

A2的条件指标也不一致：seed29汇总双重中心化相关升至0.598，但逐事件条件相关中位数仅从0.455升至0.476，符号翻转召回从8.91%降至8.75%；seed17双重中心化相关仅0.167。因此不能单凭一个较高的汇总相关判定已获得可靠条件信息。

这些结果不支持继续用少数Query共享平移补偿当前Reader。剩余页面差异、预测局部响应与质量修正的耦合仍可能影响动作；不能仅凭回归教师失败断言所有决策相关β误差都是页面特异的，更不能证明R4信息论不足。此实验没有求共享偏移的决策最优解。
