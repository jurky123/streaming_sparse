## 解释边界

尾部直接计算原始64 token的真实logits、top1/top2条件质量、代表最大logit、页β及真实页mass，包含错误移出和加入页。初始Risk误差很小不支持直接断言初选漏掉关键页；可能是交换破坏了已精算页保护，须以角色表判断。

2*tanh确实限制pooling权重比不超过e4，16token中单个权重上界约0.785；但之后代表重中心化不是凸组合，不能据上界直接推导最终Key范数或β因果效应。本轮另做单页Key的tanh/重中心化2×2反事实，冻结Value/stats/旧Risk；两个关键灾难移出页baseline可逐位重建，其余端点存在最大0.015625的BF16路径差异，不据此作精确因果结论。结果并不支持简单去除两行就解决问题，也没有重训新摘要。

新四状态由无教师固定策略生成，所有事件保留，先测条件价值后冻结Pset回放。状态范围和共同动作池同时改变，不能把结果当真实部署状态分布的最终认证。原始矩阵见审阅包。完整分布训练结果也不是最终视频质量或速度，未解封Test。
