## 训练与选择

页面映射712→64 GELU→32，输出8×4 BF16系数；共享Query128→8，phi=tanh(uA)。不增加原始KV读取，也不额外使用R4 logits。四轮4608更新，Adam1e-4，梯度clip1；不搜索超参。内层沿用E26质量因子设计X=mass[1,phi]和相对ridge1e-6，通过FP64五维solve求导。

外层按页面目标能量归一化，并用64×16×原训练zscale²作分母下限，防止巨大残差主导；这是明确的训练加权选择，不等同于未归一化总MSE。仅使用训练真标签求梯度；开发集LS系数是评价教师，未用于更新U/G。检查点按四个训练epoch中最大开发汇总真实交换收益选择，初始随机结构不参与选择。每个epoch均保留。

## 综合判断

A的学习特征在Oracle系数/真实beta下通过两个种子的门槛；B未稳定恢复这部分能力。

- seed17：B实际Oracle恢复10.67%，逐例平均改善-5.05%，退化112/288；真实beta替换恢复-13.38%。

- seed29：B实际Oracle恢复6.85%，逐例平均改善-1.64%，退化119/288；真实beta替换恢复-2.72%。

Set虽在汇总上优于同信息Independent和no-op，但大量退化及负的逐例均值仍不支持可靠在线决策。完美beta替换不能修复预测z的错误，也可能破坏两类预测误差的补偿；不能因此声称beta误差已经不重要。当前剩余瓶颈仍在有符号系数/质量的一致预测与动作排序。B采用新的损失归一化，因此与E25-D的差异不能全部归因于phi变化。按计划停止扩大该分支，不增加网络、rank、训练轮数、数据或Kernel实验。

重建损失下降不保证真实交换收益提高；checkpoints.csv保留随机初始化及全部四个epoch，按约定的开发汇总收益选择训练检查点。两个实验种子同时对应不同冻结C摘要，因此差异不能全部归因于网络初始化。未通过本次结构和训练方案也不证明R4完全没有可用信息。

数值修订：A训练后的审计发现大目标相减损失精度，因此改用2E·deltaO−||deltaO||²的等价增量式；初始和全部四个checkpoint重新评价并选择，训练权重未重跑。E26固定φ/SVD对照也在本轮用同一公式重算；修订前记录在before_stable_gain目录。因此当前恢复率可能与早期进度消息或旧E26表略有不同。
