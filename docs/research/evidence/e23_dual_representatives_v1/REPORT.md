# E23-A：冻结四代表的双视图信息诊断

阶段A完成144例；阶段B未运行。开发集主配置dual_rank8 Set平均退化0.561%，退化率44.44%，未通过预登记门槛。结果否定本轮无训练双视图读出，不证明联合训练的四代表必然无效，也不是现有摘要所有可能读出的信息上限。

## 固定设计

四代表仍执行原近似Attention和原Risk，不修改物理页、摘要或预算。R2将固定相邻代表(0,1)/(2,3)的Key和Value做算术平均，各代表质量32；其logit由已有R4 logits取均值，无新QK扫描。不得用两个R4指数权重相加冒充新的R2近似。

修正取ΔN=N4−N2、ΔZ=Z4−Z2，等价将Raw贡献外推为2R4−R2，系数与符号固定1，没有事后调参。先形成在线中心残差e_on，再由所有页面外推贡献计算估计Dense中心，修正为一致的净残差进行集合目标评价；直接把在线中心残差当精确Dense残差会遗漏中心变化，本轮已显式处理。

主配置dual_rank8为现有per-head basis的正交子空间投影；dual_full为完整128维诊断；value_rank8为已有中心化摘要Value贡献、分母修正置0的基线。每组同信息比较Set与Independent（页面平方净残差排序），同一Medium候选池、一次交换、正预测收益才执行，否则no-op。M16评分，真实Q64评价。未搜索pairing、rank、系数、阈值或网络。

划分：36city101训练描述、36city303开发决定、72horse冻结评价。先完成开发集并锁定B不启动，再运行horse。无参数拟合，完整V诊断不能反向覆盖主配置门槛。

## 成本边界

不增加永久摘要存储或原KV读取；可选读取已有mean/detail304字节/页，稳态每层按无跨tile复用估算0.100GiB。已有R4 QK约5.804GFLOPs/层属于复用项，不是新开销。两视图rank8响应主要乘加下界0.544GFLOPs/层，512动作的rank8范数下界0.113GFLOPs/层。

这些是部分算术账，未含完整V均值投影、中心化、质量/分母计算、R2指数、选择与中间状态/访存。原型为FP64诊断，不是fused低维实现；没有报告实际加速比，也不声称总新增计算一定小于几GFLOPs。
