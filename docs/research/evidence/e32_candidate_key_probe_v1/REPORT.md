# E32：候选页 Key-only 质量探测

**结论：预登记信息筛选未通过，且执行可靠性门槛未通过。** 本轮不训练、不访问 Test、不实现 Kernel，不增加到 b>4。

## 范围与固定设计

两个冻结 C/E29 模型种子17/29，各使用同一两条开发轨迹的288个 head–tile。M16决策、Q64真实 pre-W_O NMSE评价；Page64/R4、10%预算和 own保护不变。每事件初始Medium含16移出×32加入，共48个候选页，仅这些页面新增Key探测，背景β及预测局部响应完全不变。每个16-token子组均匀无放回抽 b=1/2/4，固定5个采样种子17/29/43/71/101，嵌套样本。采样位置由页面token身份和预登记种子决定，先于收益评价冻结。

每采样种子都是一次独立随机计划的完整实验；表中探测结果平均五次，不选择最佳种子、不集成五次信息。模型种子并非独立视频；1440事件×采样观测仍只对应288相关事件、两条轨迹。

质量估计为 logZprobe=logsumexp(Q·Ksample/√128)+log(16/b)，β=logZprobe−logZsummary。Z估计在抽样随机性下无偏，logZ与动作选择不是无偏；无beta裁剪、无教师校准。Set沿用解析局部响应与共同Softmax集合目标，Independent用完全相同的信息做页面独立残差能量交换；均允许no-op。

## 审计与可复现性

独立审计检查全部20,736个Set/Independent动作的合法性、count和own；重建288份标签无关采样计划与SHA；180次NumPy longdouble采样质量复算；432个选中动作独立真实混合NMSE复算与Set正质量混合评分核对。完整64Key仅用作少量数值恒等检查，不是新增实验配置。

E29/C/phi模型SHA保持不变；三个对照逐事件重放一致。离线读取完整KV用于冻结摘要和真值重建，新增探测函数仅接收Q、抽中K、摘要logZ和b，不接收V、Dense或真实页贡献。Test未读取，无训练。

原始数据在本目录 s17/s29：panel_*.npz含候选β、初始与共同面板预测/真实收益；plans包含token身份哈希与嵌套位置。精简包只包含报告、表格、协议、审计和复现源码，不包含原始QKV、模型或大型面板缓存。

## 判定边界

该实验检验的是固定预测局部响应下补充候选质量信息的价值，不能证明β是唯一瓶颈。Candidate-True/Full-True仍使用有误差的预测响应，本身不是完整真实残差Oracle；采样偶尔超过它们不意味着更准确。若信息收益改善但退化仍多，应按预设停止条件暂停扩展与Kernel，不通过增加b接近完整精算来获得“成功”。两条开发轨迹不足以声明全新场景泛化。
