# E17：真实交换收益三项分解、单标量幅度校准与真实分母诊断

本任务对应用户提出的下一轮“E16”；此前真实 Mass 对照已占用E16，因此独立保存为E17，不覆盖旧实验。

**完成144个 head–tile、994个集合、457,792个候选状态–动作。仅复用冻结数据；没有新网络、新摘要、新QKV/视频、新全局求解或在线多轮试验。** Q64/Page64、R4/rank8、10%精确预算、own保护保持不变。输入代理用16个实际probes；真实收益及三项分解使用全部64 Query。

## 结论

- **相对幅度确实失配，但单标量校准未获得稳定正收益。** 训练所得λ为Full-V 25.44、mean-only 24.08，显著减少错误执行；评价集初始Risk上的平均逐例改善仍为−0.115%和−0.075%。
- **不能把失败主要解释为分母问题。** E15 Full-V在初始Risk的46次错误执行中，28次真实交互项本身非正，14次自身能量抵消有利交互，4次由分母变化把正收益翻负。
- 真实分母诊断改善了部分排序和退化尾部，但保留原方向代理与λ=1时仍失败。现有代理对交互项的符号与幅度仍不够可靠。

这支持继续研究误差估计，而非直接部署校准后的评分；也不能据此认定必须新增K–V统计。本实验只验证一个全局比例校准与固定方向代理，未穷尽现有摘要的可预测信息。

## A：严格分解

使用冻结数据的Dense分母归一化坐标：E=Σ未精算页 e，Z=实际混合分母/Dense分母，δe=e_r−e_a，Z_new=Z−d_r+d_a。归一化常数C是全部64 Query Dense输出能量。

逐Query计算并求和：

- I = −2E·δe / Z² / C，交互项，可正可负。
- B = ||δe||² / Z² / C，自身能量，非负。
- D = ||E+δe||²(1/Z²−1/Z_new²)/C，分母变化，可正可负。
- **g = I − B + D**。

分母差采用等价的 (Z_new−Z)(Z_new+Z)/(Z² Z_new²)，范数直接正数求和，降低相减误差。全部候选与E13原收益核对，最大绝对差 **5.551e-16**。原始数据独立重算已选动作与标签最大差 **0.000e+00**。

同时保存相同16 probes上的I/B/D作为覆盖诊断；主结论始终使用64 Query。不是先平均Query残差再求范数。

### E15选错动作的算术分类

仅统计 E15 分数>0而实际g<0的动作，分类互斥且按下列顺序：I≤0；否则I−B≤0；否则由D把正的I−B翻成负收益。这是算术定位，不是独立因果贡献分摊，D仍可能加重前两类错误。

| 初始Risk评价集 | 真实交互非正 | 自身能量抵消 | 分母翻负 | 总错误执行 |
|---|---:|---:|---:|---:|
| Full-V | 28（60.87%） | 14（30.43%） | 4（8.70%） | 46 |
| mean-only | 26（57.78%） | 14（31.11%） | 5（11.11%） | 45 |

全部反事实集合按事件等权汇总：Full-V错误类别占比58.33%／34.96%／6.71%；mean-only为57.91%／34.47%／7.62%。后续集合包含局部交换与人工扰动，不代表模型自身线上轨迹。

### 所有候选的机制诊断

初始Risk中，Full-V交互符号准确率67.78%；在匹配16 probes的真实交互项上是68.05%，表明问题不能简单归因于16/64 Query不一致。全部状态对应约65.29%和64.90%。

在代理和真实交互都为正的候选中，Full-V有72.13%的候选满足 B_proxy/I_proxy < B_true/I_true；mean-only为73.58%。**这是相对交互项的自身能量惩罚偏轻，不是说B的绝对幅度总被低估。** 使用真实分母换算单位后，原始代理B/真实B的逐例中位数平均反而约3.19，因此不能混淆绝对尺度与相对比例。

所有初始候选中，5.61%由分母把固定分母正收益翻负，0.87%被分母从负收益救回；D在 |I|+B+|D| 中的平均占比约13.60%。全部状态对应6.03%、0.80%、14.90%。这些是全候选比例，不能等同于被评分器选中的错误动作比例。

完整数据含正确动作、错误动作、面板Oracle最佳动作、候选收益正负分组；见 selected_actions.csv、decomposition_*.csv、mechanism_*.csv、E15_error_categories.csv。

## B：仅一个有效全局λ

评分为 I_proxy−λB_proxy，其中 I_proxy=mean16(2H·v)，B_proxy=mean16(||v||²)。保留score>0执行、否则no-op；没有额外阈值或置信度网络。

训练只用city_walk seed101的36例/249集合，每例等权、例内状态动作等权。对真实Q64收益做非负最小二乘 aI−bB，取λ=b/a。正公共尺度a不影响排序或零阈值执行，因此在线只使用一个λ。训练标签用每例收益标准差归一化，两个特征使用同一个在线RMS缩放；标签尺度从不进入推理。λ是本拟合目标下的有效比例，不能直接宣称物理残差幅度β/α精确等于25。

开发集仅用city_walk seed303的36个初始Risk状态，在λ=1与唯一训练拟合值之间，按实际平均相对改善选择。没有网格、分层参数或多阈值搜索；冻结之后才评价horse_field的72例。即便结果负也完整报告，不再调λ。

## 真实分母诊断的精确定义

以上 oracle_current_z / oracle_full_z **均保持λ=1**，仅用于独立隔离分母影响，不与λ校准叠加：

- current_z：mean16[(2H·v−||v||²)/Z²]，真实当前权重但不引入δZ。
- full_z：mean16[||H||²/Z²−||−H+v||²/Z_new²]，使用真实交换后的分母。

两者都使用不可在线获得的真实分母，是教师诊断。current_z几乎未改善；full_z将Full-V初始平均退化从6.829%减至5.286%，mean-only从6.076%减至3.893%，但仍严重退化。全状态退化尾部改善较大，也仍未转正。

本轮**没有测试λ校准与真实分母的组合**，不推断二者联合作用；真实分母加原代理失败，也不等于任何分母预测器都无用。

## 研究判断

不能把E15失败归结为“方向已有，补一个尺度或分母即可”。相对能量比例确实失配，但校准主要收缩了执行；多数被选错误动作的真实交互项已经不利。下一步若继续，应优先解释和预测交互项的符号与相对大小，保留分母对尾部的影响；不因本轮结果直接扩大网络、改变摘要或部署评分器。

当前数据只有36个独立训练head–tile、单条训练基础轨迹，反事实集合不是独立新分布；评价场景曾用于研究；本实验不构成摘要信息论上限或新场景泛化证据。
