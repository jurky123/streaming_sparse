# E38 动作翻转归因与角色感知信息诊断

**已完成B和A；C极值诊断、D训练集阈值校准未启动。** D仅完成原E29固定提议的可分性诊断。两个模型种子各288个开发事件，来自两条轨迹。没有神经网络训练、摘要更新、新QKV采集或Test访问。

因E30缓存没有完整真实局部响应与128维摘要输出，用户明确授权离线读取已有开发KV重建冻结C摘要。仅B重建使用这些数据，A直接使用缓存；不是新增在线探测，也没有改变部署预算。

## 主要结果

1. **质量和响应错误共同影响动作间隔。** 两种子β的平均Shapley式贡献均大于响应，但联合干预明显非加性；背景区域的有符号贡献也可能为负。不能将β单独宣布为唯一瓶颈。
2. **修复原动作不等于修复决策。** 同时提供原错误动作两个端点的真实r/β后，一半以上原动作被降至非正，但重新扫描后仍频繁选择另一个有害动作。
3. **角色区分有教师价值，敏感度权重没有稳定改善。** G4-mass与G4-direction在两个种子均优于对应G2，但仍有大量退化；W_J没有产生更可靠的校准。
4. **没有启动条件分支。** 端点仅β替换拒绝比例低于锁定的25%门槛；接受特征在seed29 snow轨迹未达到AUC0.60。没有扩统计、换阈值或只选择seed17继续。

## 评价单位和信息边界

原E29、Risk mask、own保护、精算预算、M16、Medium512和一次交换/no-op均固定。初始面板512动作，五状态只用共同合法子面板。动作真值来自原Q64缓存。所有新间隔与预测分数统一除以Q64完整Dense平均能量+1e−12/64；这是离线正常数，不影响排序或no-op。旧M16缓存使用不同正归一化，按动作重放核验，而非把原始分数直接混减。

j_pred和j*都包含no-op；非正最大收益选择no-op，动作索引打破平局。相同动作保留，间隔为0。贡献与收益均保留负值。低于1e−12的真收益变化用于近零计数，执行规则仍以预测>0判断。

## 条件阶段与停止决定

C启动规则在跑B前已写入protocol：两个种子β平均贡献均为正且大于响应，并且仅端点β替换拒绝原错误动作比例均≥25%。前一项通过，后一项仅21.05%/23.08%，所以未进一步读取原始logits做极值诊断，未计算半径、未试饱和函数。25%是本轮资源筛选规则，不是极值路线不可能有效的证明。

D只完成提议可分性。规则要求两个种子、各轨迹至少一个特征AUC≥0.60，并且其预测收益三分位分箱AUC中位数≥0.60；有效箱每类至少5例。裕量I/(B+ε)在两个种子的条件AUC均约0.631，但seed29 snow的AUC为0.589；正probe比例也未补足。所以不使用训练轨迹校准网格，不产生冻结gate，不把全no-op当成功。

## 审计与成本

576事件的分支/区域归因闭合、面板不变与count/own通过；E29、TrueBeta及G2-mass动作重放E30/E37。抽取跨层/轨迹事件，以NumPy longdouble直接正混合输出差核验4顶点、8区域和六组选中动作；dE/dbeta与自动微分独立比对。Q64投影与正交补使用同一完整能量分母，B5全部事件闭合。详见audit.json与源哈希。

重建的真实响应是离线标签，不能算在线额外信息。六组偏移也依赖真实β，未构造在线校准器。W_J若未来在线计算，需全页向量归约，不能按“几个标量”忽略成本；本轮不声称加速。没有新的部署缓存、Kernel或视频实验。

## 后续设计判断

本轮支持优先关注动作端点与精算/近似角色，但同时表明：只修复当前动作端点会暴露其他错误候选，响应与质量不可简单拆开独立优化。角色教师的收益可以作为下一次表示设计的约束，不能直接变成新增四偏移模块。

更合适的下一步是判断当前在线摘要能否识别端点间的响应/质量对比及其误差，而不是继续优化全页β MSE。若需要新表示，应保持初选和真实混合输出质量，用同信息Set/Independent/no-op验证；当前结果没有授权扩大Reader、增加原始Key探测或直接实现接受gate。
