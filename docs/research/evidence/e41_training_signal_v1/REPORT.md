# E41：训练信号覆盖与梯度分配审计

**本轮完成，无训练、无模型更新、无原始KV读取，Test继续封存。完整训练集也未学到可靠集合决策；发现了局部响应监督对部分真实重要、摘要低估页面的覆盖缺口，但没有证明β梯度普遍消失或共享层长期抵消是主要原因。**

## 范围与证据口径

每种子1152个训练事件（8条轨迹）及288个开发事件（2条轨迹），合计2880个seed-event。事件在同一轨迹内相关，不是2880条独立视频。固定E29最终选定Reader、C摘要、Adaptive φ、B16、Risk、Medium和M16；实际收益按Q64完整输出评价。训练集评价的是最终冻结模型，不是历史训练中的在线表现。

参数梯度为每种子48个预先固定的训练Risk状态，覆盖8条轨迹×3层×2条件。排序四分位选样恰好集中在head6，因此不能把该参数子样本推广到其他head；完整输出梯度分析覆盖全部head。没有重放历史Adam状态或60/20/20全部训练状态，也不能声称观察到了长期梯度冲突。

## B：重要低估页面的监督覆盖

原始局部损失含m²；β为按页RMS归一化后的Huber，保留全部mean reduction。原β floor为1.5330186546，收益floor为0.0007554343，局部尺度为0.0064952183/0.0064888371。以下份额均先在事件内归一化，再对非空事件等权平均；不按layer29的大误差池化。

两种子各968个训练事件包含摘要低估十倍的Query–Page对。在这些事件内，该子集约占9.46%/9.13%的Query–Page样本、10.11%/9.95%的真实质量，却只有0.0703%/0.0692%的局部损失份额，局部输出梯度L2份额约0.0431%/0.0416%。这是实际监督覆盖差异，不只是推理敏感性假设。它不能证明改成真实质量加权就能改善决策：更高权重可能破坏现有优化平衡。

β监督必须区别看待：全体低估子集仍获得约10.53%/10.06%的β梯度L1份额，接近其真实质量份额，**不支持“β梯度在所有低估页面上消失”**。但有害动作端点中的低估子集，在90/398、103/395个有害事件中出现：其真实质量份额约1.447%/1.213%，β梯度份额只有0.125%/0.122%，KL参考分别0.940%/0.757%。该端点子集的归一化β梯度总量相对不归一化Huber的中位比约0.104/0.097；这是公式参照，不是新训练结果。覆盖缺口只涉及部分错误，不能解释所有退化。

原β监督输出梯度在非零误差处始终指向真实β，未发现符号反转。原集合损失对有害端点β的梯度L1份额约4.52%/4.14%，并没有整体忽略这些端点；其方向与“朝真实β修正”一致的Query–Page比例约48.5%/49.0%。这不说明集合目标梯度错误：在预测响应不准、目标含Q64真值的情况下，它可能通过联合调整而非逐点物理回归纠错。不能把方向不一致直接判为bug。

KL参考梯度为(α̂−α*)/16，只诊断相对质量分布覆盖，不约束共同β尺度；没有用于任何更新。`mass_coverage_summary.csv`的条件均值不可与全事件均值直接相除。主角色表同时给出全事件、layer、head和轨迹分层，重叠角色不与互斥区域份额相加。

## 数值与来源审计

全2880事件的E40原动作及真实最佳动作身份一致；输入事件、摘要和Reader检查点哈希匹配E40。原局部/β解析梯度与自动微分一致。独立使用分别归一化的正质量混合公式核验集合分数及梯度，并核验KL梯度和真实动作收益；包含预定抽查及各划分最差动作。真实增量核验明确记录绝对差，极端动作采用rtol=1e−5、atol=1e−9；不把原增量公式称为逐位精确。详情见`audit.json`、`independent_checks.csv`。

原M16前向与E40 Q64缓存切片的最大β差约1.70e−4/2.11e−4，未改变任何动作；记录在`checks.csv`。份额守恒的最大FP32舍入误差约2.11e−7，容差1e−6。梯度绝对单位受mean reduction和尺度影响，因此报告按事件的份额、范数与方向，不能把不同量纲的绝对数直接相加。

## 当前判断与后续边界

1. **完整训练集也弱**：撤回“训练已解决，只剩泛化”的解释；尾部损害尤其集中，但没有删除它们。
2. **发现有限的监督覆盖问题**：摘要低估页面的局部响应监督非常弱；部分错误端点的β监督也相对真实质量不足。β本身不是全局无梯度，集合梯度也在关注端点。
3. **未证明普遍优化抵消**：冻结子样本不支持把失败归因于β被其他目标长期压制，裁剪本身不会改变事件内比例。
4. 本轮仅支持把“质量低估与局部监督耦合”列为一个有证据的后续受控假设，而不是立即替换整个损失或加入KL。若后续获准做一次对照，应固定架构/预算，仅改变预先确定的一种覆盖机制，并同时检验训练真实收益、错误损害与开发收益；不进行多权重搜索。当前未启动该对照。

参数子样本不能覆盖实际最差的head9事件，故在选择涉及共享层优化的新方案前，应先核验该范围限制；本轮不据此追加训练。Test保持封存。
