# E49：冻结评分数值决策审计

固定E29、同预算T0、E48 Full_Pset；各1152训练/288开发事件，两种子共8640模型事件。无训练、无摘要/候选变化，Test封存。历史全部评分和选择保留；统一/增量路径仅作为数值对照，区间规则只核验历史最高提议，不改排名、不试第二名。

## 数值规则

Reader实际BF16/FP32输出与传入评分的lm/center二进制值视为精确输入。Set使用未除Dense能量的原始gain；Independent使用一个固定正缩放下的等价能量差，仅符号可与旧能量比较。指数用MPFR160位有方向舍入，基本加减乘除逐运算nextafter外向扩张；除法包含0或非有限路径给出无界区间并拒绝。区间下界>0才执行，否则no-op。这是对固定代理的数值符号核验，不保证真实收益正，也不包含Reader建模误差。

保证范围为本机IEEE754 binary64正常/非正规数与最近舍入、无fast-math、规定算术表达式。MPFR exp本身定向舍入，避免假定GPU exp误差只有一个ULP。非部署硬件通用保证。统一FP64归约与端点增量保留正项新分母；移出主导项导致端点差不稳时回退统一路径，不宣称更快。

## 范围与后续

此规则只有符号可分辨性含义，不是实际收益阈值。没有改成Dense归一化后的1e−12，也没有根据损害调宽区间。未被区间排除的真实负收益应归模型错误；本轮不据此启用温度/范数补偿、摘要训练或接受策略搜索。整体收益与最差尾部须同时判断，不能只报退化数下降。

## 最终判定

全部8640模型事件中，统一归约与交换增量路径均未改变最高动作；区间规则也没有拒绝任何历史正提议（Set/Independent均如此）。因此各基线训练/开发的净收益、H_gain、H_loss、退化与最差尾部全部保持原值。Full_Pset开发恢复仍26.00%/28.85%，退化仍69/73例，最大损害问题未被数值协议修复。

参考事件中，旧两条归约路径对同一mask确有非零差，最大输出差范数约4.40e−16、单Query raw no-op收益绝对值约9.26e−16；统一路径的重复mask差为0。但不能由“存在差异”推出它改变了实际最高动作。全量排名没有变化，高精度确认所选微小正值不是纯底噪。

两个原E29灾难动作的raw高精度gain约4.9190e−11、1.0500e−13，均落在严格正区间；它们应列为可分辨的模型误判。T0/Full_Pset在seed29灾难事件最高分为负而no-op，在seed17仍给可分辨小正分并保留错误动作。不能用一个统一归一化epsilon将这些归类为数值bug。

本轮不扩大区间、不调实际收益门槛，也不启动温度/范数、pooling或Reader训练。数值规则只审计代理计算，不构成真实安全保证。下一步若研究接受策略或新表示，必须另立协议。
