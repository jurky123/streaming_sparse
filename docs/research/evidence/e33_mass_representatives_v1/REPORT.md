# E33-A：四代表 Key 质量响应的跨 Query 容量诊断

**本轮判定：未通过容量与混合质量的联合筛选，不启动 E33-B。**

A1仅学习正权重；A2保持等权，仅拟合四个Key，Value表示冻结。结果必须分别解释质量拟合、固定原集合的输出、重新Risk选页的输出，不能以β变小替代混合输出质量。

## 预登记范围与信息边界

复用两条开发轨迹 kitchen_cook_s701 / snow_ski_s702，固定head0、layer1/15/29、chunk2/5/8、step0/2、两个tile，共72事件/模型种子，两个冻结C种子17/29。没有新QKV、网络训练、原始KV探测、Test访问或生产代码修改。基线为对应E24 Joint-C摘要与其原Risk，不是最早178f95a8摘要。

历史页由E28的有序token身份、原始KV SHA和摘要SHA匹配；本轮独立重验原始身份。tile：同chunk同step其他tile；step：同chunk其他step；forward：严格更早chunk。拟合只使用这些donor Query的真实页面logZ，目标事件64 Query全部留出。当前页与无donor历史页保持原摘要，不使用当前页教师。matched-tile/step只在三种donor条件共同支持的历史页上改变摘要，与forward比较。

每页使用单一起点、200次Adam，按donor事件/Query均匀logZ平方误差拟合。A1学习4个softmax权重，A2学习4×128个Key偏移；正则、学习率与步数先固定，仅按donor目标取最佳迭代，不按留出质量调参。A2允许脱离原pooling凸组合/均值约束，属于宽松表示诊断，不能证明现有pooling网络可以生成这些Key。未证明求得全局最优，失败也不能被称为R4容量不可能性证明。

拟合FP64；评价将新Key或正权重舍入BF16，权重重新归一化。K/V组配对、Value均值/rank8均固定。新的64π权重同时用于近似N与Z及Risk概率；Risk theta与四项公式不变，A2重新计算受影响页的Key均值偏差统计。原Reader的标签失效，本轮不复用旧Reader声称在线Set结果。

## 固定Key时，权重能修正多少质量？

对任意Query，Zweighted/Zequal=4Σπg exp(lg)/Σexp(lg)≤4，因此 logZweighted−logZequal≤log4≈1.386。这个上界不依赖拟合器；对正β>log4的部分，固定Key加权无法完全纠正。权重只能重新分配已有四点的质量，不能产生遗漏的高logit方向。

## 摘要与路由效应必须分开
