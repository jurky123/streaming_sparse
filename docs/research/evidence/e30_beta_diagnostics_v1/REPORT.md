# E30-A：页面质量修正的表达、复用与决策敏感性

仅完成A1–A3：两个冻结C/E29种子，各288例开发事件。没有训练β分支，没有改变响应Reader、摘要、Adaptive φ、B16、Risk或候选池；Test保持封存。

## 本轮判断

1. **事件内五项β表达通过容量门槛，但跨上下文复用没有通过。** OracleCoeff64填补TrueBeta差距97.38%/79.75%，Shared与LOTO却大幅下降。当前Adaptive φ适合本事件拟合，不等于能用一套固定历史页系数覆盖多个Query上下文。这个差异也可能受共享mass加权拟合和Query覆盖影响，不能归因为β目标本身依赖全局中心，更不能据此证明R4没有信息。

2. **候选页质量准确性在本次干预中更有价值。** Candidate-True恢复38.80%/53.16%，Background-True为26.01%/27.23%；但seed17的背景仍有明显贡献，不能把背景误差设为零。该结果没有证明只预测48页即可部署：仍保留其余页的现有预测，且真实β来自教师。

3. **较小的平均回归误差并不能保证更好的动作。** Shared/LOTO的普通β MAE低于原预测器，但集合收益明显更差；候选页原始MAE低于背景页，修正候选却更有决策价值。应关注Query/页面敏感性和联合质量效应，而非只优化全页平均MAE。

4. **错误动作有一定敏感性集中，但不是独有特征。** 错误执行的top8页面一阶影响集中度中位约54.89%/56.05%，正确执行约52.61%/52.91%。当前结果不支持把集中度直接变成可靠门控器。

5. **即使真实β也未满足完整可靠性标准。** True仍退化50/288、51/288例（17.36%/17.71%），P10约−2.11%/−1.99%。β是有价值的改进方向，但单独精确β不保证当前响应和搜索的全部门槛通过。OracleCoeff64在seed17的条件汇总相关也没有超过原预测器，不能只凭初始单步恢复率声称条件变化已解决。

本阶段按请求停在A1–A3。没有训练B1/B2，也没有自动增加Key方差特征。若下一步进行β-only训练，应同时面对页面系数跨上下文不稳定和TrueBeta自身可靠性不足这两项限制，不把容量通过当作预计必然成功。

## A3：回归与决策敏感性

information_summary.csv按M16/Q64、全部/候选/背景记录β MAE/RMSE，以及summary/true/predicted页面质量加权误差；权重在每事件所选区域内归一化。quality_mass_l1/l2_relative直接比较exp(logm+β)，避免单独exp(β)溢出。汇总为事件等权均值/中位数，不能混作全页统一质量权重。

action_panel行记录真实Q64交换gain的Pearson/Spearman、I符号准确率（另列匹配M16真值）、B误差、正收益判断与最佳动作regret。I/B采用净残差分子分解，未将稳定输出差公式里的二次项误当成E17的分子能量项。

对每例E29最高分提议计算gain对全部M16 β的梯度。页面敏感贡献为Σq |∂gain/∂β·(βtrue−βpred)|，报告top1/4/8集中度；对top8页面另做逐页及累计真实β修正，重新评价同一个提议动作。该排序读取真标签，是诊断而非部署候选机制。线性贡献仅是局部一阶近似，完整真实β变化可高度非线性，不能当作严格因果贡献分解。

## 结论边界与下一步

容量门槛与在线成功是两件事。即使真实β提高平均收益，仍需检查True自身的退化比例和P10；若真实β尚不能满足可靠性，单独β Head也不能被预期为必然解决全部问题。Shared包含评价标签，LOTO仍读取其他上下文标签且当前页有教师，不证明仅R4能预测固定页面系数。

本轮不进行训练、特征维度扩展、新QKV或Test评价。若原五项容量未通过，可按方案另做同五项容量的Key方差特征解析对照；不因回归误差下降而直接启动部署。若通过，再依据这些诊断决定是否执行B1/B2，不能将本报告的教师收益写成在线结果。

复现：`python -m local_experiments.e30_beta_diagnostics.run --seed 17` / `--seed 29`，然后`python -m local_experiments.e30_beta_diagnostics.report`与`audit`。使用现有项目环境，CUDA；两种子可分卡，BLAS/OMP线程1。完整完成输出受保护，不覆盖；重跑应先选择新的结果版本。


## 数值修复与独立审计

首次运行在极端拟合β下，exp(logmass+β)重构z溢出，旧公共缩放导致混合分母下溢。正式结果改为分别归一化预测全页和每个混合集合：预测精确页输出为摘要页输出＋冻结局部响应，质量用log-sum-exp；与解析局部模型在精确算术下等价。没有裁剪β、调整ridge或删除实例。Independent能量在必要时省略所有动作共享的正比例系数，保持排序和no-op。

预算/own/面板检查：8064个决策全部通过。独立longdouble混合输出复核168个选中动作，真实收益最大绝对差1.04e-09；预测评分最大绝对差6.94e-18。NumPy独立ridge复核24页。冻结模型哈希未变。

与E29原混合精度路径比较，2304个基线/TrueBeta决策中有11个动作或no-op不同；差异表记录near-tie或数值路径变化，不隐瞒。容量门槛采用本轮统一稳定计算的Predicted与True，避免混用计算路径。
