# E42：真实质量补充的局部响应监督

## 单变量协议

冻结C摘要、Adaptive φ、B16、Reader结构（51,157参数）、Risk、M16、Medium512、own及预算。β监督、集合gain/listwise损失、Adam重置与超参、全局梯度裁剪、数据划分和状态计划完全沿用E39-T0。真实质量仅用于离线训练权重，不进入Reader或推理。

`w0=m²`；逐Query固定`A=sum(w0)`，`w1=0.5*w0+0.5*A*alpha_true²/sum(alpha_true²)`。权重停止梯度，保留原局部尺度及所有mean reduction；每个Query总权重不变，每页至少保留半数原权重。总权重相同不保证梯度范数相同。

## 执行顺序

1. 固定E29输出，复用E40/E41缓存，对完整训练事件检查低估子集（m<alpha_true/10）、有害动作及Oracle动作端点的权重、损失、梯度L2份额。新旧份额先在事件内归一化、再对非空事件等权平均；不跨种子池化。
2. 每种子固定8个head9训练事件：按轨迹排序，各轨迹head9事件按原index排序取`(轨迹序号*7)%事件数`，另加E41两个最差事件。比较新旧局部及共享层梯度，有限快照不解释为长期冲突。
3. 核对T0初始化、冻结参数SHA、状态计划、Adam设置及数值路径；额外重放16步T0验证，随后丢弃。通过后复用E39-T0最终epoch1，不重训基线。
4. 仅训练T1两个种子，各2304次更新。保存epoch0/1，预先固定最终epoch1为主结果，不按开发集挑选。
5. T0/T1最终模型统一评价1152训练、288开发事件；E29实际决策基线复用E41。完整训练集与开发集同时检查，不仅使用48例监测。

## 门槛与停止

预检要求两个种子在低估子集、低估有害端点、低估Oracle端点上，事件平均权重/损失/输出梯度份额提高，并通过数值有限性、权重守恒和半权重下界检查。未通过即停止，不改混合系数。

覆盖机制有效要求两个种子完整训练集相对T0净收益提高且H_loss降低，并在开发集有同向收益。部署还需Set优于同信息Independent和no-op、两开发轨迹正收益、两种子Oracle恢复≥20%、逐例平均不退化、退化数/P10/绝对尾部改善。有限改善不等于部署成功；本轮不自动解封Test。

主要报告H_gain、H_loss、最大1/5事件损害占比、逐轨迹/layer/head结果、原低估子集和固定旧端点的响应误差与β误差。新的响应监督可能通过共享层改变β数值，不能描述为“β完全不变”。不增加KL、gate、网络、KV探测、缓存或推理工作量。
