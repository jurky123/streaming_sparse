# 下游监督路由：独立消融

其他权重、KV上限、10%精确页预算、16 probes均固定。训练只更新6层×3 heads的路由θ，其余层/head保持原值。训练city_walk、reef_fish；验收horse_field、traffic_crossing，seed101，前段RGB[21,101)。

每条标签只改变一个head，在72个query tile各替换一个未受保护的边界页，比较真实两步x₀误差。训练监督是整组替换的偏好，不冒充单页独立贡献或完整视频梯度。
