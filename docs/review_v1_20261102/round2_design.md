# 校准修正、扩大训练与验收计划

## 校准不能只看拟合loss

原Adam/softplus版本只归一化标签，四类特征尺度跨度很大。新增按训练数据的特征列RMS和标签尺度归一化，求解四维非负Huber凸问题（NNLS初始化、L-BFGS-B、投影梯度/KKT检查）。旧求解器保留于 calibration_adam_reference.py。

求解器问题已经定位并修复：第29层训练Huber loss由1091.8降至0.437，留出预测/标签均值比由296.3降至0.737，最优性条件通过。但同预算留出attention NMSE在6个事件中全部变差，约2%–42%。该候选未被接入扩大版本。

这验证了评审中的限制：单页残差范数拟合更准，并不保证一个页集合的向量残差更小；稳健回归还可能低估少数大误差head。不能将凸目标收敛等同于选页质量通过。

本轮保守候选只以训练集标签总和/预测总和计算每head的正尺度，四特征相对系数保持不变。6个留出事件的实际mask全部一致（changed_mask_entries=0），预测/标签均值比0.895–1.109。它改善整体尺度，未解决逐页误差建模，也尚未授权开启动态预算。相同预算下不冒称额外选页收益。

## 已完成的扩大训练

city_walk、reef_fish两场景，seed0，29层，chunk2/5/8，step0/2，每事件2次摘要更新。共348事件、696次更新，348事件的训练loss均下降。每层7类摘要/分组特征参数均检查有限非零梯度；骨干冻结。

真实两步下游训练使用学生闭环状态，第一步输出经scheduler作为第二步输入，以同学生raw KV状态的Dense分支输出作为teacher。硬分组和路由无新增STE，theta在后续单独拟合。层0使用独立缓存副本，block checkpoint保存每步上下文。更新参数后刷新历史摘要但不跨页改变已提交的raw KV；之后废弃旧标签并重新采样。

首个chunk2事件已实际通过：下游NMSE 0.0944024，训练/普通前向NMSE=0，第一步梯度范数0.00120544；203个参数张量（29×7）均非零且有限。它只是一个训练事件，不是下游质量已改善的证明。

## 扩大采样暴露的标签范围问题

696个学生状态事件中有4个非有限标签，均为layer28/head11，特征与最终attention输出有限。保留原始异常文件，仅在相同checkpoint和相同轨迹上重新计算这4个事件；clean latent逐位一致校验通过后才继续。

修复仅涉及离线标签：FP64分母比值和以最大分量缩放的范数，避免指数和平方归约溢出。极端标签单元测试通过。修复后的实际标签最高约7.20e64；没有截断或删除这些样本。这也说明以ZD归一化的逐页残差可很大，不能把它直接等同于最终attention输出误差，恒等式中的ZD/ZS不能忽略。

每head的完整物理校准尺度保存在metadata；固定预算路由只使用数值范围合适的正比例分数单位，仍保持页排序。诊断比较时恢复物理单位。动态预算依然未启用，不能据此宣称逐页风险预测或动态误差控制已经通过。
