# 实验结果快照

本目录保存提交时已完成实验的原始 JSON 指标、配置和身份信息。manifest.json 记录来源、时间及 SHA256；运行中的实验仍可继续产生新结果，本快照不自动更新。

模型权重、KV、视频、clean latents 和日志保留在本机 artifacts/review_v1_20261102，不提交到 Git。JSON 中的 checkpoint 路径是本机产物引用，不表示权重已随仓库发布。

当前下游监督路由为 6 层 × 3 heads 的小规模试验，共 72 条标签。两组前段视频均退化，不能作为已验收模型。当前运行时为质量参考实现，共享 GPU 耗时不构成速度验收。
