# 单步 flow 蒸馏验收

起点为摘要预训练；冻结骨干和硬路由θ，训练29层的7类稀疏摘要/分组特征参数。两个训练场景，各chunk2、5和四个实际推理时间步，共16次更新。损失为原生flow的逐元素MSE，学生与dense教师共享输入、时间步、文本及历史。这里只验证可微模块的flow蒸馏，未重新采集硬路由排序标签。

主验收为seed101、RGB[21,101)，同分辨率、KV上限和10%选页预算。共享卡不作速度验收。
