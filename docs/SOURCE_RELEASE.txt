Read docs/EXPERIMENT_SUMMARY.txt for key results, protocols and limitations.

checkpoint hashes or trained models required to reproduce the reported results.

Historical REBUILD.md describes v0.8 data/model recovery; later experiment setup
and collection scripts build on those assets and on prior Opt configurations.
Machine-specific paths in existing launch/status scripts may need adjustment.

Additional CUDA backend source dependency:
  bash migration/fetch_sparse_backend.sh
This downloads the pinned public SpargeAttn source into the ignored vendor path.
CUDA compilation remains on demand. Upstream license and attribution accompany
local adaptations. Model/data downloads and GPU training are separate actions.

The main empirical environment is 8 x NVIDIA A100 40GB. This source upload is
validated for Python/shell syntax and upload content; it does not certify that
a data-free fresh clone can immediately launch the trained experiments.
